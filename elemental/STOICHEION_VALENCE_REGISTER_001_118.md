# STOICHEION Valence Register v2 — 16-Series

This register uses the user's symbolic STOICHEION value language, **not conventional chemical valence notation**.

```
. = 1
| = 2

10 = ..||..|          :: NEON
16 = ..||..|....|     :: full 16-series shell
```

The register is append-only in full 16-unit shells:

```
n = q*16 + r

glyph(n)
=
[..||..|....|] repeated q times
+
canonical remainder glyph(r)
```

The exact scalar identity is tested for every element 1..118.
